Added preview :data:`cocotb.preview.Feature.STRICT_RESOLVE` which ensures calls to :func:`cocotb.types.Logic.resolve` and :func:`cocotb.types.LogicArray.resolve` return :class:`cocotb.types.Bit` or 0/1-only :class:`cocotb.types.LogicArray`, respectively. This changes the behavior of ``Logic('W').resolve("weak")`` to result in a :exc:`ValueError` instead of ``X``.
