:envvar:`COCOTB_BOOTSTRAP` and the ``cocotb_bootstrap`` library were added. This bootstrapper library is loaded by the simulator first in the standard flow, directly after the simulator starts. The :envvar:`COCOTB_BOOTSTRAP` environment variable describes an arbitrary number of native libraries (``.so``, ``.dll``, or ``.dylib``), and entry point functions in those libraries, which are loaded by the bootstrapper library.
