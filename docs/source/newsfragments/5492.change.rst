:class:`~cocotb.handle.PackedObject` is now the abstract base class of :class:`~cocotb.handle.PackedArrayObject`, :class:`~cocotb.handle.PackedStructObject`, and :class:`~cocotb.handle.PackedUnionObject`. Packed Verilog objects are discovered as one of these concrete types on simulators that report packed structs and unions distinctly from vectors. ``isinstance(handle, PackedObject)`` keeps working.
